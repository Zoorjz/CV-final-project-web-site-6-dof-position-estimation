Первый блок

Основной задачей нашего исследования была разработка системы отслеживания положения перекладины силового роботического тренажера в 6 измерениях (3x positions, 3 x rotations).

Реализация данного функционала позволит добавить следующие функции в силовой тренажёр:

  • Повышение безопасности при выполнении упражнений
  • Классификация упражнения по траектории движения
  • Геймификация тренировок

Основным ограничением было ограниченные мощности Raspberry pi 4B и требование real-time трекинга

Второй блок

Были сравнены между собой два подхода:

  • Geomentry based
  • PnP
  • Data driven
  • One shot CNN regression
  • ML with handcrafted features

Ниже находятся два видео с разными реализациями.

Для изучения разных подходов вы можете просмотреть визуализации на каждом из этапов алгоритомов Pipeline Stage Timeline .

Вы можете симулировать real time работу на raspberry py 4 включив toggle

Вы можете отобразить Ground truth позицию cобранную с помощью Meta Touch Pro controller включив toggel



Третий блок

Можно обратить внимание, что самым быстрым имплементацией является PnP который ограничен только кадрами в секунду камера поддержривает 75 FPS (max 100 FPS for PnP on raspberry pi 4)

Вторым по эффективности (скорости?) идет ML feature regressior c 25 FPS, Хотя и со значительно хуже точностью предсказания позиции.

Самый худший результат скорости показал CNN c 5 FPS. Несмотря на значительно худшую скосроть и среднюю точность, данная реализаций единственная способна справиться с нештатными ситуациями, такими как засвет от окна, отражения, случайные блики.
